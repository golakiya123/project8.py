# 🔢 NumPy Analyzer

A beginner-friendly, menu-driven Python project for creating and
exploring **1D, 2D, and 3D NumPy arrays**. Perform mathematical
operations, combine or split arrays, search and filter values, and
calculate useful statistics from the command line.

> Built with Python and NumPy as a hands-on project to practice array
> manipulation and numerical computing.

## ✨ Features

-   **Create arrays:** 1D, 2D, and 3D arrays
-   **Mathematical operations:** addition, subtraction, multiplication,
    and division
-   **Combine or split:** concatenate arrays and split an array into
    parts
-   **Search, sort, and filter:** locate values, sort elements, and
    filter by threshold
-   **Statistics:** sum, mean, median, standard deviation, and variance
-   **Interactive menu:** simple command-line navigation

## 🛠️ Built With

-   **Python**
-   **NumPy**

## 🚀 Getting Started

### 1. Install NumPy

``` bash
pip install numpy
```

### 2. Download or clone this repository

``` bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Open the project folder and run:

``` bash
python project8.py
```

> If your Python file has a different name, replace `project8.py` with
> your filename.

## 📋 How to Use

1.  Run the Python file.
2.  Choose **Create Array** and select 1D, 2D, or 3D.
3.  Enter the required dimensions and values.
4.  Select an operation from the main menu.
5.  Follow the prompts to view the result.
6.  Choose **Exit** to close the program.
